Scene Recognition for Automated Environmental Analysis

Abdulrehman Munir

Roll No: SU92-BSCSM-F23-453

With the exponential increase in visual data from satellites, drones, and user uploads, manually categorizing landscape imagery is highly inefficient. This project develops an automated Deep Learning system to classify natural scenes into six distinct categories: buildings, forests, glaciers, mountains, seas, and streets. By comparing a custom-built CNN against a Transfer Learning (MobileNetV2) approach, we evaluate the trade-offs between computational resources, training time, and classification accuracy.

Comparative Architecture Analysis

To evaluate environmental scene classification thoroughly, this project contrasted a bespoke architecture trained completely from scratch against a state-of-the-art pre-trained transfer learning model. Below is the technical breakdown of their trade-offs across computational complexity, feature extraction capability, and inference behavior.

Custom CNN (Scratch)

Baseline
  • Sequential Structure: Built with custom stacked Conv2D layers, MaxPooling, and Dropout regularization.
  • Learning Dynamics: Learns hierarchical edge-to-shape feature detectors purely from target environmental images without external priors.
  • Resource Profile: Requires significantly higher epoch iterations and higher memory overhead during backpropagation.
Weights File: model_scratch.h5 Export: model_scratch.tflite

MobileNetV2 (Transfer)

Optimized
  • Inverted Residuals: Utilizes lightweight depthwise separable convolutions to dramatically cut parameter counts.
  • ImageNet Priors: Inherits robust pre-trained feature extractors, allowing rapid convergence and superior generalization on complex textures.
  • Inference Speed: Delivers lower latency and higher confidence stability across ambiguous outdoor environments (e.g., forests vs. mountains).
