Scene Recognition for Automated Environmental Analysis

Abdulrehman Munir

Roll No: SU92-BSCSM-F23-453

With the exponential increase in visual data from satellites, drones, and user uploads, manually categorizing landscape imagery is highly inefficient. This project develops an automated Deep Learning system to classify natural scenes into six distinct categories: buildings, forests, glaciers, mountains, seas, and streets. By comparing a custom-built CNN against a Transfer Learning (MobileNetV2) approach, we evaluate the trade-offs between computational resources, training time, and classification accuracy.
